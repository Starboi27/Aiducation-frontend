# UI/UX 및 기능 요구사항 (v1.4)

## 1. 디자인 규칙 (Aesthetics)
- **주요 색상**: 모든 버튼과 강조 텍스트는 보라색 계열(`#6C5CE7`)을 사용해야 함.
- **레이아웃**: 퀴즈 화면에서 보기는 5지 선다형(5개 옵션)으로 구성되어야 함.

## 2. 기능 규칙 (Functionality)
- **퀴즈 생성**: 토픽당 최소 5문제 이상의 퀴즈가 생성되어야 함.
- **해설**: 정답 여부와 상관없이 모든 문제에 대해 상세한 해설(`explanation`)이 포함되어야 함.
- **로딩**: AI 분석이나 생성 중에는 사용자에게 진행 상태(`progress`)를 시각적으로 보여줘야 함.
